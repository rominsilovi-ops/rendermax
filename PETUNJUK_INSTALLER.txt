STUDIO MUSIK OTOMATIS — PAKET PEMBUAT INSTALLER WINDOWS 11
===========================================================

Paket ini membuat installer Windows melalui GitHub Actions. Python, PyInstaller,
FFmpeg, FFprobe, dan Inno Setup dipasang otomatis pada komputer build milik
GitHub. Anda tidak perlu memasang Python atau FFmpeg di PC Windows 11 Anda.

PENTING
- Ini adalah paket sumber dan konfigurasi build, bukan installer EXE yang sudah jadi.
- Build memerlukan koneksi internet dan akun GitHub.
- Setelah installer diunduh dan dipasang, proses render berjalan lokal di PC.
- Build belum dapat dijamin berhasil sebelum workflow selesai dijalankan di runner Windows.

CARA UPLOAD KE GITHUB
1. Buat atau buka repository GitHub.
2. Ekstrak ZIP ini di komputer.
3. Unggah SELURUH ISI folder hasil ekstrak ke halaman utama repository, bukan folder induknya.
4. Pastikan susunannya persis seperti berikut:
   .github/workflows/build-windows.yml
   studio_musik.py
   StudioMusik.iss
   PETUNJUK_INSTALLER.txt
5. Klik Commit changes.

CARA MEMBUAT INSTALLER
1. Buka tab Actions di repository.
2. Pilih workflow "Buat Installer Windows 11".
3. Klik Run workflow, pilih branch main, lalu klik Run workflow sekali lagi.
4. Tunggu hingga status hijau (centang).
5. Buka hasil run yang berhasil dan unduh artifact bernama
   Installer-Studio-Musik-Otomatis-Windows11.
6. Ekstrak ZIP artifact dan jalankan
   Setup_Studio_Musik_Otomatis_Windows11.exe.

JIKA BUILD GAGAL
Buka job yang merah, perluas langkah yang merah, lalu salin pesan error terakhir.
Jangan menjalankan ulang berulang kali sebelum penyebab error diperiksa.

FITUR APLIKASI
- Menambahkan beberapa file audio dan mengatur urutan playlist.
- Memilih video latar yang diputar berulang.
- Menampilkan judul lagu berdasarkan urutan waktu.
- Mengatur crossfade antar lagu.
- Mengekspor video MP4 landscape 16:9 atau portrait 9:16.
- Membuat timestamp YouTube dan playlist M3U.

CATATAN
- Uji dahulu dengan beberapa lagu sebelum proyek panjang.
- Render 2K/4K dan playlist ratusan lagu memerlukan ruang disk, memori, dan waktu besar.
- Gunakan musik dan video yang Anda miliki atau berizin untuk digunakan.
